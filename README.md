# 🤖 LangGraph AI Assistant

A modern AI chatbot built with **LangGraph**, **Groq Llama 3.3**, and **Streamlit**, featuring a premium glassmorphism interface, animated UI, and stateful conversations.

---

# ✨ Features

* 🤖 AI-powered chatbot using **Groq Llama 3.3 70B Versatile**
* 🧠 Stateful conversations with **LangGraph**
* 💬 Real-time chat interface
* ✨ Premium Glassmorphism UI
* 🌈 Animated background and smooth transitions
* ⌨️ Typing indicator animation
* 📊 Live conversation counter
* 🔄 New Chat & Clear Chat functionality
* 📱 Responsive design for desktop and mobile
* ⚡ Ultra-fast inference powered by Groq

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/hamza-maqsood-ai/langgraph-chatbot.git
```

Go to the project folder:

```bash
cd langgraph-chatbot
```

Create a virtual environment:

```bash
python -m venv env
```

Activate it:

### Windows

```bash
env\Scripts\activate
```

### macOS / Linux

```bash
source env/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 🔑 Environment Variables

Create a `.env` file in the project root.

```env
GROQ_API_KEY=your_groq_api_key_here
```

---

# ▶️ Run the Application

```bash
streamlit run streamlit_frontend.py
```

Open your browser:

```
http://localhost:8501
```
